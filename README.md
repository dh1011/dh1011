### Featured projects

- **[hjkl: learn Vim by doing](https://hjkl.duy.run)**: Short, hands-on Vim editing challenges in the browser covering motions, text objects, search, marks, counts and repeats. Free, no sign-up.
- **[Zed Mini](https://github.com/dh1011/zed-mini)**: A minimal fork of the Zed code editor focused on local text editing. It keeps the core editor and LSP support and drops AI, terminal, plugins, collaboration and telemetry, taking the app from ~400 MB to ~100 MB. Rust, macOS.
- **[Subscription Manager](https://github.com/dh1011/subscription-manager)**: A self-hosted subscription and expense tracker with a calendar view, per-account summaries, multi-currency support and ntfy/Gotify payment reminders. Next.js, SQLite, Docker.
- **[LLM-Term](https://github.com/dh1011/llm-term)**: A CLI that turns plain-English prompts into shell commands, shows the command and asks before running it. Rust, plus a portable C/Cosmopolitan build.
- **[start:ichi](https://github.com/dh1011/start-ichi)**: A minimal, terminal-style browser startpage for organizing bookmarks. React, self-hostable with Docker.
